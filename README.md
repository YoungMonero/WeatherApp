# Weather App

A simple and modern **Weather App** built with **HTML, CSS, and JavaScript** that fetches real-time weather data using the **OpenWeatherMap API**.  
Users can search for any city to instantly see the current temperature, humidity, wind speed, and weather condition icon.

---

## Features

- Search weather by city name  
- Displays temperature, humidity, and wind speed  
- Dynamic weather icons (Clouds, Clear, Rain, Drizzle, Mist)  
- Smooth animations and clean UI  
- Real-time data powered by [OpenWeatherMap API](https://openweathermap.org/api)

---

## How It Works

1. The user types a city name into the input field.  
2. When the **Search** button is clicked, the app fetches weather data from OpenWeatherMap using the city name.  
3. The weather details (temperature, humidity, wind speed) and the appropriate weather icon are displayed dynamically.

---

## Tech Stack

- **HTML5** – Page structure  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – API requests and DOM manipulation  
- **OpenWeatherMap API** – Real-time weather data
